# ZverTBot — технический паспорт

**Версия документа:** 1.0.0
**Дата актуализации:** 2026-08-14
**Назначение:** описание возможностей, архитектуры, потоков данных и взаимодействия компонентов ZverTBot.

## Описание

ZverTBot — Telegram-бот для управления VPN-сервером с поддержкой двух протоколов:

- **Xray (VLESS + REALITY)** — VPN-доступ на базе Xray.
- **AmneziaWG** — WireGuard с обфускацией для сложных сетей.

### Назначение

- **Администратору** — управление VPS через Telegram: клиенты, мониторинг, логи и резервное копирование.
- **Клиентам** — доступ к своим VPN-конфигурациям, статистике и поддержке после привязки Telegram-аккаунта.
- **Автоматизация** — сбор трафика и GeoIP-данных, мониторинг служб и резервное копирование.
- **Интеграция** — передача эксплуатационных метрик в Home Assistant.

### Ключевые особенности

- **Два VPN-протокола** — Xray (VLESS + REALITY) и AmneziaWG.
- **Система привязок** — до четырёх VPN-клиентов на один Telegram-аккаунт.
- **Накопительный учёт трафика** — статистика сохраняется между перезапусками.
- **GeoIP-аналитика** — определение страны, города, провайдера и ASN.
- **Модульная архитектура** — разделение Telegram-обработчиков, ядра, бизнес-логики и системных интеграций.
- **Защита операций** — валидация входных данных, контроль доступа и межпроцессная сериализация операций с клиентами.
- **Systemd-интеграция** — запуск бота и системных компонентов в штатной инфраструктуре VPS.
- **AI-диагностика логов** — анализ журналов служб для выявления ошибок и потенциальных проблем.

## Функциональные возможности

### Администратор

#### Управление клиентами

- Создание и удаление клиентов Xray и AmneziaWG.
- Переименование VPN-клиентов.
- Генерация конфигураций и QR-кодов для подключения.
- Отправка конфигураций через Telegram.
- Просмотр статистики трафика клиентов.
- Поиск клиентов по имени.

#### Система привязок

- Привязка VPN-клиентов к Telegram-аккаунтам.
- Создание заявок на привязку пользователем.
- Одобрение и отклонение заявок администратором.
- Отвязка VPN-клиентов от Telegram-аккаунта.
- Просмотр ожидающих заявок и активных привязок.

#### Управление службами

- Управление состоянием Xray, AmneziaWG и ZverTBot.
- Перезапуск системных служб через Telegram.
- Просмотр журналов основных служб.
- Управление Fail2ban: просмотр состояния и работа с блокировками IP.
- Мониторинг системных процессов.
- Управление SSH-ключами и просмотр истории подключений.
- AI-диагностика логов служб для выявления ошибок и потенциальных проблем.

#### Сетевые инструменты

- Проверка скорости сетевого соединения.
- Определение внешнего IP-адреса клиента.
- Сканирование сетевых портов VPS и выявление потенциально нежелательных открытых портов.

#### Резервное копирование

- Ручной запуск резервного копирования через Telegram.
- Автоматическое резервное копирование по расписанию.
- Хранение резервных копий локально и в облачном хранилище.
- Просмотр состояния и истории выполненных резервных копий.

#### Аналитика и отчёты

- **Отчёты по трафику** — сводная статистика использования VPN.
- **Статистика бота** — учёт использования команд и активности пользователей.
- **История действий** — журнал основных административных операций.

#### Мониторинг VPS

- **Статус сервера** — CPU, RAM, Disk, Swap, Uptime, процессы и состояние служб.
- **GeoIP-аналитика** — определение страны, города, провайдера и ASN подключений.
- **Онлайн-статус клиентов** — определение активности Xray и AmneziaWG.

### Клиенты

#### Личное меню

- **Статистика** — просмотр собственного объёма трафика.
- **Конфигурация и QR-код** — получение данных для подключения.
- **Правила маршрутизации** — получение файла `ru_geo.conf` и инструкций по использованию.
- **Инструкции** — справочная информация по подключению.
- **Поддержка** — создание и просмотр обращений через тикетную систему.

#### Контроль доступа

- Доступ предоставляется только к VPN-аккаунтам, привязанным к Telegram-пользователю.
- При наличии нескольких аккаунтов пользователь выбирает нужный аккаунт в промежуточном меню.
- Управление другими клиентами и системными службами недоступно.

### Автоматизация

#### Сбор данных

- **Трафик клиентов** — периодический сбор и накопительный учёт трафика.
- **Метрики VPS** — периодический сбор системных показателей и состояния служб.
- **GeoIP-аналитика** — обновление данных о подключениях.
- **Онлайн-статус** — определение активности клиентов Xray и AmneziaWG.
- **Защита операций с клиентами** — межпроцессная блокировка исключает конфликты между изменением клиентов и сбором статистики.

#### Резервное копирование

- Поддерживается автоматическое и ручное резервное копирование эксплуатационных данных проекта.
- Архивы могут сохраняться локально и в облачном хранилище.

#### Уведомления

- **Watchdog HA-туннеля** — контроль состояния соединения Home Assistant с VPS.
- **Uptime Kuma** — мониторинг системных служб и передача событий в Telegram.

#### Интеграция с Home Assistant

- `stats-http.py` предоставляет эксплуатационные данные через HTTP.
- Home Assistant использует эти данные для отображения состояния VPS, VPN и клиентов.

## Команды бота

### Доступные пользователям

| Команда | Описание |
|---|---|
| `/start` | Открывает главное меню в соответствии с правами доступа пользователя. |
| `/help` | Открывает то же меню и справочную точку входа. |
| `/my_id` | Показывает Chat ID и позволяет создать заявку на привязку, если доступ ещё не предоставлен. |

### Администратор

| Команда | Описание |
|---|---|
| `/rename СтароеИмя НовоеИмя` | Переименовывает VPN-клиента. |
| `/bind username chat_id` | Привязывает VPN-клиента к Telegram-аккаунту. |
| `/unbind chat_id` | Удаляет привязку VPN-клиента. |
| `/pending` | Показывает ожидающие заявки на привязку. |
| `/history` | Показывает историю действий. |
| `/status` | Показывает текущий статус VPS. |
