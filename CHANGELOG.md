# Changelog

Все заметные изменения ZverTBot.

## [1.1.0] - 2026-09-10

### Added

#### Установка

- Добавлена возможность устанавливать Xray отдельно с помощью `-xray`.
- Добавлена возможность устанавливать AmneziaWG отдельно с помощью `-awg`.
- Добавлена возможность устанавливать оба VPN-компонента одновременно.
- Installer теперь устанавливает rclone через официальный install script.
- Добавлены примеры конфигураций Xray и AmneziaWG для первоначальной настройки.

#### Xray

- Добавлена проверка готовности конфигурации VLESS Reality перед созданием клиента.
- Добавлена проверка обязательных параметров Reality-конфигурации.
- Создание Xray-клиента блокируется, если серверная конфигурация не готова.

#### AmneziaWG

- Добавлена проверка готовности серверной конфигурации AmneziaWG перед созданием клиента.
- Проверяется наличие необходимых параметров интерфейса: `PrivateKey`, `Address` и `ListenPort`.
- Создание AWG-клиента блокируется, если серверная конфигурация не готова.

#### Backup

- Добавлено отображение реального прогресса загрузки backup в Telegram.
- В процессе загрузки отображаются процент выполнения, переданный и общий объём данных, скорость и оставшееся время.
- Добавлено сохранение длительности backup в статусе.

### Changed

#### Xray

- Информация о Xray-клиенте в Telegram теперь формируется по фактическим портам и SNI из конфигурации, а не по заранее заданному набору портов.

#### Backup

- Улучшена обработка retention локальных backup: текущий создаваемый архив не удаляется во время очистки.
- Улучшена обработка retention удалённых backup: текущий архив не попадает под удаление.
- Обновлена логика получения статистики загрузки через rclone.
- Улучшена работа ручного backup в Telegram: одно сообщение обновляется по мере выполнения операции и затем заменяется итоговым результатом.
- Добавлена информация о продолжительности backup в итоговое сообщение.

#### Home Assistant

- Список Xray-клиентов в статистике теперь очищается от дубликатов.
- Xray-клиенты в traffic collector группируются по UUID и могут быть связаны с несколькими inbound/портами.

### Fixed

- Исправлено дублирование сообщений при отображении прогресса загрузки backup.
- Исправлено дублирование Xray-клиентов в данных Home Assistant.
- Исправлена обработка текущего backup механизмом retention.

### Documentation

- Существенно обновлена документация по deployment и установке.
- Документированы режимы установки Xray и AmneziaWG.
- Добавлены примеры конфигураций VPN.
- Документированы проверки готовности конфигураций перед созданием клиентов.
- Обновлена документация по backup, rclone и отображению прогресса.
- Обновлена документация по Home Assistant и статистике VPS.

### Tests

- Добавлены тесты проверки готовности Xray-конфигурации.
- Добавлены тесты проверки готовности AmneziaWG-конфигурации.
- Обновлены тесты lifecycle AWG с учётом требований к конфигурации.
- Расширены тесты deployment.
- Добавлены и расширены тесты статистики VPS и Xray traffic collector.
- Обновлены тесты backup retention и ручного backup.
- Полный набор тестов проходит успешно: **1434 passed**.
